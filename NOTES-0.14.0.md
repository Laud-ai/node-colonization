# 0.14.0 — Needs tree, supplier cards, map-first layout

Tiago's request (needs tree / supplier menu / map-first UI). UI + read-only analysis; no rule changes.

- **Map-first layout**: the Moon/Mars globes fill the screen. Every other panel is a **side window** (Needs tree, Suppliers, Legal moves, Earth blocs, Solar independents, Game settings, Selected colony, Colonies, Event log, Solar map strip): dock left/right (⇄), minimize to the bottom tray (–), close (×) and reopen from **Windows ▾**. Layout is remembered in this browser (Game settings → Reset windows). Top bar keeps Turn / Acting / Phase, Auto-resolve, End turn, Found, Simulate N, New game.
- **Needs tree** (opens when you click a pin, or 🌳 in Selected colony): the node dependency tree, Resources at the top. ✓ bloc color = the colony has it; ✗ red = missing (Requires ★, under-covered deps causing strain, missing basals); grey = **no-stress expansion** (developing it would add no strain — computed with the engine's own `strainOf`, see `src/needs.ts`).
- **Supplier menu**: click any node → cards for every place that has it (Earth blocs with a free excess slot, colonies, Independents). Card = name, Earth/Moon/Mars badge, centered flag (L6 flag generator), resource symbol, own-bloc/ally/neutral/rival, regional vs outer (space), which line would carry it, what it fills/replaces (Requires → develop, strain removed, extra import), ally cost (Earth excess slot / export leg), and blocks (no reach, East/West lock, won't export). **All needs** (no filter) lists all suppliers sorted: Requires first → logistically possible → other needs → expansions; within that own bloc / allies → neutral → rival, then the engine's own source rank. When the selected colony is the acting one, legal choices get an **Import / Switch / Borrow** button that runs the same move as the Legal moves list.
