# 0.13.1 — Pin markers on the Moon / Mars globes

Presentation only (Tiago's approved pin design); no rule or engine changes.

- **Pins are the default marker** (Solar view → Pins / Glyphs; choice remembered in this browser). The Sep 1 level glyphs stay selectable.
- **Head** = bloc color (same as the colony card); **Independent** = white head with black outline. **Bold level number** in the head, constant on-screen size so it reads at any zoom.
- **Stem height by tier**: short L1–4, medium L5–9, tall L10+.
- **Fervor ring** around the head fills toward the independence threshold: green (<50%), amber (50–80%), red (≥80%). Independents have no ring.
- **Specialty badge** (top-right, node color + short code: H₂O, O₂, Fd, En, Lg, Mil, TF, …).
- **Alerts**: pulsing red outline = strain or a running food/water/O₂ clock; crossed swords = proxy-war agitation or named in an invasion this/last turn; dashed outline = founded this turn.
- Hover still shows the full card (now with specialty, requires, fervor x/threshold and alerts).
- **Readability**: dark bloc colors get a light halo (pins and glyphs) so they read on the grey Moon; stems have a dark sleeve.
